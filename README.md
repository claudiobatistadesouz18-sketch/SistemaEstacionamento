# SistemaEstacionamento
Sistema simples de gerenciamento de estacionamento feito em Java.

## Sobre o projeto

Este projeto foi feito como atividade da disciplina de Java.

O objetivo é criar um sistema simples para controlar um estacionamento.

## Funcionalidades

- Cadastrar clientes.
- Cadastrar veículos.
- Registrar entrada dos veículos.
- Registrar saída dos veículos.
- Calcular o valor do estacionamento.
- Consultar o histórico.

## Regras do estacionamento

- Valor de R$ 5,00 por hora.
- Tolerância de 15 minutos sem cobrança.

## Tecnologias utilizadas

- Java
- NetBeans

## Como executar

Abra o projeto no NetBeans e execute a classe principal para iniciar o programa.
